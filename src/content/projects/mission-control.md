## Overview
mission-control is the central coordination repository for home network, homelab, cloud services, automation, and development environment configuration. It unifies all infrastructure configuration in one place, making the entire stack reproducible and auditable from a single source of truth.

## Key Features
- Homelab service configuration and deployment specs
- Home network management and DNS configuration
- Automation workflows for cross-service tasks
- Cloud service configuration and secrets management scaffolding
- Development environment bootstrap scripts

## Tech Stack
YAML, Shell, Docker, Ansible, various IaC tooling
